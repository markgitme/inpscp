Troubleshooting

Something not behaving?

Every keyboard fault has a write-up that names the measurement that settles it, the threshold it uses, and the fix that follows — in one long page, in the order you would work through it.

Why is my keyboard not typing?

Nothing types at all. Establish first whether the computer can see the keyboard, then work down the stack from the application to the hardware.

Why are some keys on my keyboard not working?

Dead keys are almost always physical. A key that never registers and a key that registers unreliably look the same on the keyboard itself.

Why does my keyboard type the wrong character?

Nearly always a layout mismatch rather than a broken keyboard. The physical key never moves; the system decides what it means.

Why is my keyboard ghosting?

The keyboard cannot tell which of several keys closed its circuit, so it registers the wrong combination or drops one entirely.

Why does my keyboard feel laggy?

Two different faults share the name: input delay, which is usually the display, and key chatter, which is a worn switch.

Why is one key stuck down?

Mechanically stuck, usually a swollen keycap or something sticky underneath. The character repeats until you can clear it.

FAQ

Keyboard test questions

How do I test if my keyboard is working?

Use the key tester at the top of the page. Press each key in turn and the matching cap lights up on the map. Keys that never light up are dead or obstructed, keys that stay lit after you have released them are mechanically stuck, and keys that fire twice for one physical press are chattering — the tester flags those as double-fires. Walk the whole keyboard once and any problem key stands out immediately — this is the fastest keyboard test there is.

Why do my function keys never light up?

Because the operating system or browser has claimed them before the web page sees them. F1–F4 frequently switch tabs, F5 reloads, and F11 toggles full screen. On a plain keyboard with no remapping software installed, the browser will deliver the event and the cap will light. The absence of that behaviour is a browser limitation, not a hardware fault.

What is a normal typing speed?

For everyday use, 40–60 words per minute with high accuracy is comfortable. Touch typists often sit at 70–100, and professional transcription work goes considerably higher. The useful thing to measure is your own change over time, because a sudden drop in accuracy almost always has a hardware explanation while a drop in speed usually does not.

My keyboard has a UK layout. Will the layout test still work?

Yes. The detection reads the physical position of each key, and the UK and US boards have identical positions for the letter keys — they differ only in the symbols printed on them. A UK board will correctly report as US QWERTY, with the difference visible in the symbol keys. The test reports the base letter layout for exactly this reason.

Can I test a laptop's built-in keyboard?

Yes, and it is often where problems show up first. Laptop keyboards are frequently limited to two-key rollover, and the scissor or membrane mechanism underneath behaves differently from a mechanical board. A degraded laptop keyboard is also the most likely cause of a machine that "types on its own" — a failing key or a corroded flex cable is usually the reason.

What if a key registers but produces the wrong character?

That is almost always a layout mismatch rather than a broken key. Run the layout detection: it reports what your physical board is, and you can compare it with the layout your operating system has selected. If the two disagree, change the setting in the keyboard preferences and the problem disappears immediately.

Is a high latency figure a real hardware problem?

Rarely on its own. Most of the delay in this measurement is the operating system and the display rather than the keyboard — the panel measures your refresh rate so you can see how much of the figure belongs to the screen. Judge the hardware on the jitter figure rather than the mean: consistent timing with some baseline delay is normal, whereas a high and erratic timing is what actually affects how a keyboard feels in use.
